# 원가 시세 예측 검증 (pipelines/backtest_prices.py)

시뮬레이터는 재료 원가를 "계절 기준선(달별 배수) + 과거 같은 시기 범위"로 움직인다. 이 방식이 "지금 값 그대로"보다
1·3·6개월 앞을 더 잘 맞히는지, 과거 범위가 실제 값을 얼마나 담는지 롤링 백테스트로 확인했다 (각 시점에서 그때까지 자료만 씀, 최소 24개월 학습).

| 품목 (서울 생활물가지수, 경락가) | 6개월 앞 평균 오차: 계절 기준선 | 그대로 유지 | 과거 범위 안에 든 비율 |
|---|---|---|---|
| 돼지고기 | 4.9% | 6.3% | 49% |
| 제주 돼지 경락가 | 7.2% | 17.6% | 60% |
| 삼겹살 외식 | 3.5% | 1.1% | 44% |
| 닭고기 | 3.3% | 3.1% | 64% |
| 쌀 | 7.4% | 6.5% | 51% |
| 달걀 | 5.4% | 3.2% | 46% |
| 식용유 | 9.2% | 5.7% | 64% |
| 우유 | 2.1% | 1.1% | 44% |

결론
- 계절 배수는 돼지고기(소비자가·경락가)에만 쓴다. 다른 품목은 지금 수준을 그대로 둔다 (web/src/mock/quickfood.ts SEASONAL_OK).
- 과거 범위(가장 싼 해~가장 비싼 해)는 실제 값의 절반쯤만 담는다. 화면에서 "범위 밖으로 갈 수 있다"고 알린다.
- 제주 경락가 변화와 서울 돼지고기 소비자물가 변화의 상관은 같은 달 0.31, 한 달 뒤 0.36, 두 달 뒤 −0.09로 약하다. 경락가가 소매가를 한 달쯤 앞선다고 말하기에는 근거가 약하다 (45개월).
- 더 필요한 자료: 삼겹살 도매가와 전국·서울 경락가 시계열.
